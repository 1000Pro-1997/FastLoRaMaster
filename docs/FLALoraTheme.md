# FLA Lora Theme

테마별 프리셋으로 **로라를 적용하고 프롬프트를 조합**하는 노드입니다.
노드 하나가 테마 하나를 담당하고, 여러 개를 체인으로 이어 씁니다.

- 클래스: `FLALoraTheme`
- 표시 이름: `FLA Lora Theme`
- 카테고리: `FLA`
- 구현: [`nodes.py`](../nodes.py), [`presets.py`](../presets.py), [`api.py`](../api.py), [`web/fla_lora_theme.js`](../web/fla_lora_theme.js)

---

## 화면 구성

```
theme  [표정 ▼]
( ● 놀람 )                    ← 프롬프트 토글 + 프리셋 선택
[ 프롬프트 텍스트 ...        ]
[ * 저장 ][ ⚙ 옵션 ]
┌──────────────────────────┐
│ 로라 적용 (2/3)      ( ● )│
│ ( ● expression/hotarue…  │
│         ◀ 0.90 ▶      ✕ )│
│ ＋ 로라 추가               │
└──────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| `theme` 드롭다운 | 테마 선택. 바꾸면 프리셋 목록이 갱신됩니다. |
| 프리셋 줄 **토글** | 이 노드의 프롬프트를 넣을지 여부. 끄면 전체가 회색이 됩니다. |
| 프리셋 줄 **이름** | 누르면 그 자리에서 프리셋 목록이 열립니다. |
| 프롬프트 칸 | 프리셋 내용. 고치면 저장 버튼이 활성화됩니다. |
| `저장` | 변경이 있으면 빨간 `*` 가 붙습니다. 변경이 없으면 눌러도 반응하지 않습니다. |
| `⚙ 옵션` | 새로만들기 / 이름 바꾸기 / 삭제 |
| `로라 적용` 토글 | 끄면 로라를 하나도 적용하지 않습니다. **개별 토글은 건드리지 않습니다.** |
| 로라 줄 | 토글(on/off) · 이름(누르면 교체) · `◀ 0.90 ▶`(강도) · `✕`(삭제) |
| `＋ 로라 추가` | 목록에서 고른 뒤에만 줄이 추가됩니다. |

로라 이름에 마우스를 올리면 전체 경로가 툴팁으로 나옵니다.

## 입출력

### 입력

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `theme` | COMBO | O | 테마. `presets/` 의 하위 폴더 목록 |
| `preset` | STRING | O | 선택된 프리셋 이름 (UI가 채움, 화면에서 숨김) |
| `prompt` | STRING | O | 프롬프트 텍스트 |
| `lora_data` | STRING | O | 로라 목록 JSON (UI가 관리, 화면에서 숨김) |
| `prompt_enabled` | BOOLEAN | O | 프롬프트 사용 여부 (화면에서 숨김) |
| `loras_enabled` | BOOLEAN | O | 로라 사용 여부 (화면에서 숨김) |
| `model` | MODEL | — | 없어도 동작. 없으면 로라를 건너뜁니다 |
| `clip` | CLIP | — | 위와 같음 |
| `prompt_in` | STRING | — | 앞 노드의 프롬프트. 연결하면 앞에 이어붙입니다 |

### 출력

| 이름 | 타입 | 설명 |
|---|---|---|
| `MODEL` | MODEL | 로라가 적용된 모델 (입력이 없으면 `None`) |
| `CLIP` | CLIP | 로라가 적용된 클립 |
| `prompt` | STRING | `prompt_in` + 이 노드의 프롬프트를 `, ` 로 이은 것 |

## 두 개의 바이패스

프롬프트와 로라를 **각각 독립적으로** 끌 수 있습니다.

| 프롬프트 | 로라 | 적용 로라 | 출력 프롬프트 |
|---|---|---|---|
| 켬 | 켬 | 1개 | `base, my prompt` |
| 켬 | 끔 | 0개 | `base, my prompt` |
| 끔 | 켬 | 1개 | `base` |
| 끔 | 끔 | 0개 | `base` |

로라를 꺼도 **각 로라 줄의 on/off 상태는 그대로 남습니다.** 다시 켜면 원래대로 돌아옵니다.

## 데이터 저장

### 프리셋 파일

```
presets/
  <테마>/
    <프리셋>.json
```

```json
{
  "prompt": "surprised, wide eyes",
  "loras": [
    { "path": "expression\\hotarueye.safetensors", "strength": 0.9, "enabled": true }
  ]
}
```

- 프리셋은 **기본 제공이 없습니다.** 사용자가 직접 만듭니다.
- 마지막 프리셋을 지우면 테마 폴더도 함께 사라집니다. 단 폴더에 다른 파일이 있으면 남깁니다.
- 프리셋 목록은 **모든 워크플로가 공유**합니다. 어느 프리셋을 골랐는지만 워크플로에 저장됩니다.

### 이름 규칙

`새로만들기` 와 `이름 바꾸기` 는 `테마/프리셋` 형식을 받습니다.

- `자세/서있기` → `자세` 테마에 `서있기` 생성 (테마가 없으면 만듭니다)
- `서있기` → 현재 테마에 생성
- 이름 바꾸기에서 테마를 바꾸면 프리셋이 **그 테마로 옮겨갑니다**

## API

`api.py` 가 등록하는 라우트입니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/fla/themes` | 테마 목록 |
| GET | `/fla/presets?theme=` | 해당 테마의 프리셋 목록 |
| GET | `/fla/preset?theme=&name=` | 프리셋 내용 |
| GET | `/fla/loras` | 설치된 로라 전체 |
| POST | `/fla/preset/save` | 프리셋 저장 |
| POST | `/fla/preset/delete` | 프리셋 삭제 (빈 테마 정리 포함) |
| POST | `/fla/preset/rename` | 같은 테마 안에서 이름 변경 |
| POST | `/fla/theme/create` | 테마 생성 |
| POST | `/fla/theme/rename` | 테마 이름 변경 |

## 주의할 점

**위젯 순서** — JS로 추가한 위젯은 전부 `serialize = false` 입니다. 화면 배치를 위해 순서를 바꾸지만, 저장·복원 시 `flaOriginalOrder` 로 원래 순서를 되돌립니다. 이 처리를 빼면 프롬프트 칸에 프리셋 이름이 들어가는 등 값이 밀립니다.

**`NONE` 상수** — `presets.NONE` 과 JS의 `NONE` 은 값이 같아야 합니다(`"-"`). 언어에 따라 바뀌면 비교가 깨집니다.

**여러 테마 쓰기** — 노드를 여러 개 놓고 `MODEL`/`CLIP` 을 체인으로, `prompt` 출력을 다음 노드의 `prompt_in` 에 연결합니다.
