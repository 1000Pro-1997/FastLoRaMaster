# FLA Resolution

해상도를 골라 **가로/세로 정수**로 내보내는 노드입니다.
목록에서 고르거나, 한쪽 변과 비율로 정하거나, 직접 입력할 수 있습니다.

- 클래스: `FLAResolution`
- 표시 이름: `FLA Resolution`
- 카테고리: `FLA`
- 구현: [`nodes_resolution.py`](../nodes_resolution.py), [`resolutions.py`](../resolutions.py), [`api.py`](../api.py), [`web/fla_resolution.js`](../web/fla_resolution.js)

---

## 화면 구성

```
┌──────────┬────────────────────┐
│ SDXL     │  1216x832 (19:13)  │   ← 그룹 1/3 · 해상도 2/3
├──────────┴────────────────────┤
│ W ◀1216▶   H ◀832▶     ( ● ) │   ← 크기 + 비율 연동 토글
├───────────────────────────────┤
│          19:13          ( ○ ) │   ← 비율 + 가로세로 스왑 토글
├───────────────────────────────┤
│ 목록 수정                ( ○ ) │
└───────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| **그룹 칸** (왼쪽 1/3) | 누르면 `그룹 > 항목` 폴더 구조로 열립니다. `★ 즐겨찾기` 그룹이 맨 위에 있습니다. |
| **해상도 칸** (오른쪽 2/3) | 누르면 **현재 그룹의 목록이 바로** 열립니다. 폴더를 거치지 않습니다. |
| `W` / `H` 숫자 | 비율 연동이 **켜짐**이면 해상도 드롭다운, **꺼짐**이면 그 자리에서 직접 입력 |
| `◀ ▶` | 8씩 증감 |
| **비율 연동 토글** | 켜면 한쪽을 바꿀 때 반대쪽이 비율에 맞춰 따라옵니다 |
| **비율 줄** | 누르면 비율 목록(1:1, 16:9 …). 연동이 꺼지면 회색으로 비활성화됩니다 |
| **스왑 토글** | `W` 와 `H` 값을 **맞바꿉니다.** 칸의 숫자와 비율 표기가 함께 뒤집힙니다 |

각 줄에 마우스를 올리면 설명 툴팁이 나옵니다.
| `목록 수정` | 아래에 편집기가 펼쳐집니다 |

---

## 세 가지 사용 방식

**목록에서 고르기** — 그룹 칸이나 해상도 칸을 눌러 선택합니다. 크기가 목록과 일치하면 그 이름이, 아니면 `manual` 이 표시됩니다.

**한쪽 변 + 비율** — 비율 연동을 켜고 `W` 나 `H` 중 하나만 정하면 나머지가 비율대로 계산됩니다. 비율은 아래 줄에서 따로 고릅니다.

**직접 입력** — 비율 연동을 끄면 두 값을 독립적으로 넣을 수 있습니다. 숫자를 누르면 팝업 없이 그 자리에서 고칩니다.

## 입출력

### 입력

| 이름 | 타입 | 설명 |
|---|---|---|
| `width` | INT | 가로. 실제 출력의 근거가 되는 값 |
| `height` | INT | 세로 |
| `preset` | STRING | 선택된 목록 항목 이름 (표시용) |
| `group` | STRING | 현재 그룹 이름 (UI가 관리) |
| `ratio` | STRING | 비율 표기 (`"16:9"`) |
| `link_ratio` | BOOLEAN | 비율 연동 |
| `swap` | BOOLEAN | 예전 방식의 잔재. UI는 값을 직접 맞바꾸므로 항상 `false` 입니다 |

모두 위젯이며 화면에서는 커스텀 UI가 대신 그립니다.

### 출력

| 이름 | 타입 | 설명 |
|---|---|---|
| `width` | INT | 가로 (8의 배수) |
| `height` | INT | 세로 (8의 배수) |
| `info` | STRING | `1216 x 832  (19:13)  SDXL / 1216x832 (19:13)` |

---

## 계산 규칙

1. `width` / `height` 를 그대로 가져옵니다
2. `swap` 이 켜져 있으면 서로 바꿉니다
3. **8의 배수로 내림**합니다 (최소 64)

JS는 값을 넣을 때 **8의 배수로 반올림**해 저장하므로, 화면에 보이는 값이 파이썬을 통과해도 그대로 남습니다. 새 기능을 넣을 때 이 일치를 깨지 않도록 주의하세요.

비율 표기는 약분해서 만듭니다. `1920x1080` → `16:9`. 약분이 안 되면 `1.71:1` 처럼 소수로 씁니다.

## 목록 데이터

```
resolutions_default.json   ← 패키지 동봉. 영어 그룹명. 절대 수정하지 않음
resolutions.json           ← 사용자 파일. 없을 때만 기본에서 복사
```

```json
{
  "SDXL": [
    { "w": 1024, "h": 1024, "favorite": true },
    { "w": 1152, "h": 896,  "favorite": false }
  ]
}
```

- 라벨은 저장하지 않고 `w`, `h` 로 **자동 생성**합니다 → `1152x896 (9:7)`
- `favorite` 가 켜진 항목은 `★ 즐겨찾기` 그룹에 모이고, 원래 그룹에서도 `★` 가 붙습니다
- 목록은 **모든 워크플로가 공유**합니다

기본 그룹은 `SDXL`, `SD 1.5`, `Video`, `Flux HiRes` 네 개입니다.

## 편집기

`목록 수정` 을 켜면 나옵니다.

```
─ SDXL ────────────────
★  W 1024   H 1024   ✕
☆  W 1152   H 896    ✕
＋ 현재 크기를 목록에 추가
↺ 기본 목록으로 초기화
```

| 요소 | 동작 |
|---|---|
| `★` / `☆` | 즐겨찾기 토글 |
| `W` / `H` 숫자 | 누르면 그 자리에서 수정 (8의 배수로 정렬) |
| `✕` | 삭제. 그룹이 비면 그룹도 사라집니다 |
| `＋` | 지금 노드의 크기를 원하는 그룹에 추가 |
| `↺` | `resolutions.json` 을 지우고 기본값을 다시 복사 |

모든 변경은 즉시 파일에 저장됩니다. 편집기를 닫으면 노드 높이가 원래대로 줄어듭니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/fla/resolutions` | 평평한 목록(즐겨찾기 우선) + 원본 그룹 구조 |

## 주의할 점

**그룹 이름에 `/` 를 넣지 않습니다.** 드롭다운이 `"그룹 / 항목"` 형식을 쓰므로 파싱이 깨집니다. 실제로 `Flux / High-res` 로 지었다가 해상도를 못 찾는 버그가 있었습니다.

**같은 크기가 여러 그룹에 있을 수 있습니다.** `1024x1024` 는 `SDXL` 과 `Flux HiRes` 양쪽에 있습니다. 표시 이름은 **현재 그룹 것을 먼저** 찾습니다.

**스왑은 값을 맞바꿉니다.** 예전에는 `swap` 플래그만 켜서 파이썬이 출력에서 뒤집었는데, 그러면 화면의 `W`/`H` 칸이 그대로라 아무 일도 안 한 것처럼 보였습니다. 지금은 두 값을 실제로 교환하므로 칸과 비율 표기가 함께 바뀝니다.

`W`/`H` **라벨은 절대 뒤집지 않습니다.** 라벨만 바꾸면 값과 어긋나 엉뚱한 쪽이 수정됩니다.
